# 中药饮片化验室检验计算器

中药饮片成品检验中需要计算的项目，一页一个计算器。
只有计算表格、公式和判定 —— 没有版头、签名栏、页码，也没有工具条。
纯静态页面，无框架、无依赖、无后端，数据只存在浏览器本地。

**在线使用：** https://dishihao.github.io/tcm-lab-calculators/

---

## 五个计算器

| 项目 | 药典依据 | 计算公式 |
|------|----------|----------|
| 杂质 | 通则 2301 | X = M₁ / M总 × 100% |
| 水分 | 通则 0832 第二法 | X = (W₀ + W样 − W₁) / W样 × 100% |
| 总灰分 | 通则 2302 | X = (W₁ − W₀) / W样 × 100% |
| 浸出物 | 通则 2201 冷浸法 | X = (W₁ − W₀) × V / (W样 × (1 − 水分) × V样) × 100% |
| 含量测定 | 通则 0512 液相 / 通则 0521 气相，外标法或内标法 | 按所选定量方法与是否按干燥品计算自动切换 |

辅助计算：

- **相对偏差** = \|X₁ − X₂\| / (X₁ + X₂) × 100%
- **RSD**（系统适用性）= 样本标准差(n−1) / 平均值 × 100%
- **恒重差值**校验：自动比对两次干燥/灼烧称量，超过 0.3 mg 时标黄提示
- **理论板数**判定：液相默认 ≥3000、气相默认 ≥10000，可改

## 含量测定：液相 / 气相

页内「方法」下拉可在**高效液相色谱法（0512）**与**气相色谱法（0521）**之间切换。
外标法公式相同；气相模板还支持内标法、按干燥品/非干燥品口径和两成分总量判定。

### 气相品种模板

| 品种 | 待测成分 | 定量方法 | 干燥品折算 | 理论板数 | 法定限度 |
|------|----------|----------|------------|----------|----------|
| 广藿香 | 百秋李醇 | 内标法（正十八烷） | 是 | ≥50000 | ≥0.22% |
| 艾叶 | 桉油精、龙脑 | 外标法 | 是 | ≥50000 | ≥0.050%、≥0.020% |
| 八角茴香 | 反式茴香脑 | 外标法 | 否 | ≥30000 | ≥4.0% |
| 薄荷 | 薄荷脑 | 外标法 | 是 | ≥10000 | ≥0.20% |
| 丁香 | 丁香酚 | 外标法 | 否 | ≥1500 | ≥11.0% |
| 千年健 | 芳樟醇 | 外标法 | 是 | ≥20000 | ≥0.20% |
| 小茴香 | 反式茴香脑 | 外标法 | 否 | ≥5000 | ≥1.4% |
| 鸦胆子 | 油酸 | 内标法（苯甲酸苯酯） | 是 | ≥5000 | ≥8.0% |
| 亚麻子 | 亚油酸、α-亚麻酸 | 外标法 | 是 | ≥20000 | 合计 ≥13.0% |
| 香薷 | 麝香草酚、香荆芥酚 | 外标法 | 是 | ≥1700 | 合计 ≥0.16% |

选择模板会预填经质量标准核实的成分名称、色谱方法、定量方法、干燥品口径、
理论板数和标准限度；称样量、浓度、峰面积等批次数据仍由检验人员填写。
各模板的已填数据分别保存在浏览器本地，来回切换不会互相覆盖。

亚麻子和香薷按两个成分的总量判定。算出当前成分后，将另一成分平均含量录入，
页面会自动求和并按总量限度判定。

## 修约

修约规则固定为药典的**四舍六入五成双**。

**平均值的修约位数由标准规定自动推导** —— 填 `3` 就修约到整数位，填 `3.0` 修约到一位小数，
填 `0.050` 修约到三位小数。这不是拍脑袋定的，是从原始记录里反推出来的规律：

> 同一个「杂质」项目，限度写「不得过 **3%**」的报告值是 **1%**，
> 写「不得过 **3.0%**」的报告值是 **1.1%**。
> 平均值一律修约到与限度相同的位数。

所以只要限度填对，位数就对了，不需要维护一张按品种分的对照表。

### 检查类（杂质 / 水分 / 总灰分 / 浸出物）

- **平均值** = 标准规定的位数
- **单值**与限度无关，按项目固定：杂质 1 位，水分 / 总灰分 / 浸出物 2 位
- **相对偏差** 固定 1 位

### 含量测定

三个位数全部挂在标准规定上：

| | 位数 | 限度 0.15% 时 |
|---|---|---|
| 含量 X | 标准规定 **+1** | 0.310% |
| 平均含量 | 标准规定 **相同** | 0.31% |
| 相对偏差 | 标准规定 **−1**（不小于 0） | 1.0% |

举例：限度 `0.050`（3 位）→ X 4 位、平均 3 位、偏差 2 位；
限度 `1.0`（1 位）→ X 2 位、平均 1 位、偏差 0 位。
标准规定留空时，平均含量按 2 位兜底。

以上都可以用页内的「修约位数」下拉手动改写；**一旦手动改过，该项就固定，不再跟随限度**。
改动「平均含量」的位数时，未手改过的「含量 X」与「相对偏差」会跟着一起变（仍是 +1 / −1）。

另一个要点：**平均值与相对偏差由修约后的单值导出**，与化验员在纸上的算法一致。
若直接用未修约值计算，会出现"表上写 0、程序算 0.5"这类对不上的情况。

## 验证

计算引擎以三份真实批记录逐项反算校验，**42 项逐值比对全部一致**：

| | 记录值 |
|---|---|
| 白鲜皮 杂质（限度 3%） | 1.3 / 1.3 → **1%**，偏差 0 |
| 白鲜皮 水分 | 13.59 / 13.67 → 13.6%，偏差 0.3 |
| 白鲜皮 浸出物 | 23.94 / 24.38 → 24.2%，偏差 0.9 |
| 白鲜皮 梣酮 | Ā对 441741.8，RSD 0.5，0.2268 / 0.2289 → 0.228% |
| 白鲜皮 黄柏酮 | Ā对 1317450.2，RSD 1.4，0.310 → 0.31% |
| 焦栀子 杂质（限度 3.0%） | 1.1 / 1.1 → **1.1%**，偏差 0 |
| 焦栀子 水分 | 1.11 / 1.13 → 1.1%，偏差 0.9 |
| 焦栀子 总灰分 | 5.24 / 5.19 → 5.2%，偏差 0.5 |
| 焦栀子 栀子苷 | Ā对 436392.2，RSD 0.2，4.44 / 4.43 → 4.4% |
| 薄荷 薄荷脑（气相） | Ā对 787.944，样1 476.36 / 样2 467.42 |

上表中的**相对偏差**按原记录都是 1 位小数。现行规则（标准规定 −1 位）会与之不同：

| 成分 | 限度 | 偏差位数 | 原记录 | 本工具 |
|------|------|----------|--------|--------|
| 梣酮 | 0.050%（3 位） | 2 | 0.4 | 0.46 |
| 黄柏酮 | 0.15%（2 位） | 1 | 1.0 | 1.0 |
| 栀子苷 | 1.0%（1 位） | 0 | 0.1 | **0** |

栀子苷这类限度只有一位小数的，偏差会修约到整数位而显示为 0。
如不合用，把该页「相对偏差」的位数下拉手动调一位即可（手改后固定）。

**另一处与原记录不一致：薄荷 RSD。**
本工具按样本标准差（n−1，药典与色谱工作站通行做法）算得 **0.9%**，原记录写 0.8%。
若改用总体标准差（n）则为 0.76% → 0.8%。白鲜皮黄柏酮的记录（1.4%）只有用 n−1 才能对上，
同一套记录里两种算法并存，故本工具统一采用 n−1。两个值都远低于 ≤2.0% 的限度，不影响判定。

## 使用说明

### 水分的填法
浸出物与含量测定里的水分（Q）一律按**百分数**填（例：`13.6` 表示 13.6%），
程序内部自动换算为小数参与 (1 − 水分) 运算。

### 恒重
水分、总灰分、浸出物的计算一律取**恒重后**（第二次干燥/灼烧，即"1 小时"行）的称量值。
两次称量差值会实时显示，超过药典规定的 0.3 mg 时标黄提示。

### 含量测定的纯度 S
药典所载外标法公式**不含**纯度 S，故默认不做纯度折算。
如贵司 SOP 要求按纯度校正 C对，可在该页勾选「按纯度 S 折算」。

### 数据与打印
填写内容自动存在浏览器 localStorage，刷新不丢。换批次时手动清空即可。
打印用浏览器的 Ctrl+P，输出会自动去掉页签与提示，只留表格和结果。

## 本地运行
