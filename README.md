# 中药饮片化验室检验计算器

复刻纸质《成品检验原始记录》版式的网页计算器，覆盖中药饮片成品全检中需要计算的全部项目。
纯静态页面，无框架、无依赖、无后端，数据只存在浏览器本地。

**在线使用：** https://dishihao.github.io/tcm-lab-calculators/

---

## 包含的计算器

| 项目 | 药典依据 | 计算公式 |
|------|----------|----------|
| 杂质 | 通则 2301 | X = M₁ / M总 × 100% |
| 水分 | 通则 0832 第二法 | X = (W₀ + W样 − W₁) / W样 × 100% |
| 总灰分 | 通则 2302 | X = (W₁ − W₀) / W样 × 100% |
| 浸出物 | 通则 2201 冷浸法 | X = (W₁ − W₀) × V / (W样 × (1 − 水分) × V样) × 100% |
| 含量测定 | 通则 0512 HPLC 外标法 | X = Ā × C对 × f样 / (Ā对 × W样 × (1 − Q) × 1000) × 100% |

辅助计算：

- **相对偏差** = \|X₁ − X₂\| / (X₁ + X₂) × 100%
- **RSD**（系统适用性）= 样本标准差(n−1) / 平均值 × 100%
- **恒重差值**校验：自动比对两次干燥/灼烧称量，超过 0.3 mg 时给出提示

另有一张**成品检验报告书**汇总页，自动汇集各项结果并给出总体符合性结论。

---

## 特点

- **按纸质表算，不按理论值算**：平均值与相对偏差均由**修约后的单值**导出，与化验员在纸上的算法一致。若直接用未修约值计算，会出现"表上写 0、程序算 0.5"这类对不上的情况。
- **药典修约规则**：默认"四舍六入五成双"，可切换为常规四舍五入。修约位数按项目单独可调（单值 / 平均值分别设置）。
- **代入过程可见**：每页在公式下方自动列出 X₁、X₂ 的完整代入算式，可直接誊抄到纸质记录。
- **限度自动判定**：按品种预置标准规定，自动打出"符合规定 / 不符合规定"并勾选对应方框。
- **打印即表格**：`打印本页` 输出 A4 版式，去掉所有界面元素，保留受控文件版头、签名栏和页码。
- **数据不出本机**：填写内容存在浏览器 localStorage，可导出/导入 JSON 交接班或存档。

## 验证

计算引擎以两份真实批记录（白鲜皮 250101、焦栀子 250102）逐项反算校验，
点击工具栏「载入示例」可复现：

| | 记录值 | 本工具 |
|---|---|---|
| 白鲜皮 水分 | 13.59 / 13.67 → 13.6%，偏差 0.3 | ✅ 一致 |
| 白鲜皮 浸出物 | 23.94 / 24.38 → 24.2%，偏差 0.9 | ✅ 一致 |
| 白鲜皮 梣酮 | Ā对 441741.8，RSD 0.5，0.2268 / 0.2289 → 0.228% | ✅ 一致 |
| 白鲜皮 黄柏酮 | Ā对 1317450.2，RSD 1.4，0.310 → 0.31% | ✅ 一致 |
| 焦栀子 杂质 | 1.1 / 1.1 → 1.1%，偏差 0 | ✅ 一致 |
| 焦栀子 总灰分 | 5.24 / 5.19 → 5.2%，偏差 0.5 | ✅ 一致 |
| 焦栀子 栀子苷 | Ā对 436392.2，RSD 0.2，4.44 / 4.43 → 4.4% | ✅ 一致 |

示例数据中的峰面积等取自扫描件手写体，个别末位数字可能与原件有一位出入；
公式本身已由上述多组数据交叉验证。

> **关于示例数据**：仓库内置的示例仅保留称量值、峰面积等**计算所需的数值**，
> 用于验证公式。单位名称、检验单号、仪器编号、对照品批号、文件编号等标识信息
> 均已替换为占位值。单位名称是可编辑字段，填一次会同步到全部页面。

## 使用说明

### 修约位数
每页可单独设定"单值"与"平均值"的小数位。默认值按各品种报告习惯预置
（如水分单值 2 位、平均 1 位；梣酮单值 4 位、平均 3 位）。请按贵司 SOP 调整。

### 水分 / 浸出物 中的水分填写
一律按**百分数**填（例：`13.6` 表示 13.6%），程序内部自动换算为小数参与 (1 − 水分) 运算。

### 含量测定的纯度 S
纸质表所印公式**不含**纯度 S，故默认不做纯度折算，以保持与受控表格一致。
如贵司 SOP 要求按纯度校正 C对，可在该页勾选「按纯度 S 折算」。

### 恒重
水分、总灰分、浸出物的计算一律取**恒重后**（第二次干燥/灼烧，即"1 小时"行）的称量值。
两次称量差值会实时显示，超过药典规定的 0.3 mg 时标黄提示。

## 未包含的项目

以下项目在原始报告中标注为「引用原料检验」或为定性判断，**没有独立计算过程**，故未设计算器：

- 二氧化硫残留量（引用原料检验报告）
- 铝盐、镁盐（溶液浑浊度目视判断）
- 性状、鉴别（薄层 / 显微，定性）

如需增补，请提供对应的原始记录页。

## 本地运行

无需构建，任意静态服务器即可：

```bash
python -m http.server 8000
```

然后访问 http://localhost:8000

直接双击 `index.html` 也能用（localStorage 在 `file://` 下同样可用）。
