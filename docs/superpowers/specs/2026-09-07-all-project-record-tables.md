# 其他检验项目按源记录展示填写和计算表格

用户确认：其他项目按气相方式选择品种后切换原记录表格；只展示需要填写或计算的表格。

范围：液相、杂质、水分、灰分、浸出物、二氧化硫、显微、薄层、理化。原料、成品、地区和炮制记录独立，以 template.id 关联。源记录是唯一表格权威。不得依据同名品种或质量标准补造不存在的表格。签字、日期、审批、封面、操作步骤正文不进入表格展示。

要求：保留源表固定宽度、行列、合并、字体、公式和固定文字；手机横向滑动。可填字段沿用项目状态和初始化；计算仅接入经核对的字段，不猜公式。气相既有实现及所有项目标准/限度/修约维持现有行为。干燥条件和对照品来源若有对应字段，分别展示固定文字“——”和“中检院”。

无表格记录明确记录无表状态，来源缺失/歧义/不能解析的对象单独列入人工核对项，不能静默套用通用表。发布以明确映射和浏览器验证为前提。

源 Word 只读，原件哈希前后相等；只允许对经签名核验的扩展名错配源创建临时副本。全部原始 OOXML、源路径、哈希、图像及表编号放在 ignored output 下，浏览器只接收安全的运行时布局及字段。
