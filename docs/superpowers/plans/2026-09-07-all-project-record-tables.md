# 其他检验项目原记录表格实施计划

**Goal:** 用户选定品种、原料/成品记录后，只展示该记录需要填写或计算的表格。

**Architecture:** 全量源记录只读表格清单 → 各项目 template.id 精确映射 → 经核对的安全布局/字段 → 既有状态和计算适配 → 浏览器验收。沿用气相渲染经验，不按相似品种猜布局。

**Tech Stack:** PowerShell、Word COM、OOXML、Node.js、原生 HTML/CSS、Playwright。

**Spec:** docs/superpowers/specs/2026-09-07-all-project-record-tables.md

## Global Constraints

- 仅显示填写或计算表格；排除审批、签名、日期、封面和纯步骤正文。
- 原料、成品、地区和炮制记录分别映射；原件只读，记录哈希，私有证据保留本地。
- 不猜测缺失字段/对象/公式，不用其他品种填补空缺。
- 33 个现有气相模板继续工作；已授权验证后直接推送 main。

## 实施顺序及验收

1. 全量源清单：`tools/inventory_record_tables.ps1` 逐文件只读提取 WordOpenXML 和表格段落上下文，按文件哈希断点续扫。`output/record-table-inventory/` 保存原始证据、表格文本、结构和处理状态。核对全部适用 .doc/.docx，无重复/漏项/未报告失败。
2. 对应关系：使用现有四组模板资产的 kind/sourceFile 查到唯一源文件，按源项目标题及表格位置识别候选表。多成分液相以具体成分及上下文区分。每个模板状态必须为已核对表格、源无表格或待核对原因。
3. 定量表实现：先质量项目和二氧化硫，再液相；从原始表中提取安全结构，映射现有计算字段，核对平行次数、单位、公式及输出位置。保留固定参数和初始化，逐类适配后执行对应浏览器测试。
4. 定性表实现：显微/薄层/理化只展示实际存在的结果/数据表；无表记录不将步骤正文拼成表格。每个表单保存到所选模板独立状态，初始化清可填数据。
5. 验证交付：检查 source mapping 完整性、安全布局无私有数据；代表性结构的 Word/浏览器图像比对；全部模板渲染及输入、恢复、初始化、移动端、打印验证；全部既有回归通过后提交并推送 main。
